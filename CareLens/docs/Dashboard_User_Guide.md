# How to use the dashboard

Open `dashboard/index.html` in Chrome, Edge or Firefox.

1. **Pick a page** with the buttons at the top: Overview, Patient flow, Departments, Resources.
2. **Filter** with the four boxes: From / To month, Department, Admission type. Every number and chart updates. **Reset** clears them.
3. **Hover** over a point on a line chart to see its exact value.
4. On **Departments**, click a row to focus the whole dashboard on that department. Click it again to undo.
5. The green box at the top of each page is a one-sentence summary of what you are looking at.

**Reading the colours:** green = normal value, orange = target or warning line (85% occupancy target).

**Good to know:** the "How patients arrive" chart ignores the admission-type filter on purpose, otherwise it would only ever show one bar.
