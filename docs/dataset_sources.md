# Dataset Sources

This document describes the datasets used by the Hospital Performance Intelligence System.

## 1. Hospital Dataset

| Property | Details |
|---|---|
| Original filename | `healthcare_dataset (1).csv` |
| Location | `data/raw/healthcare_dataset (1).csv` |
| Source | Provided by the internship provider |
| Original row count | 55,500 |
| Purpose | Patient admissions, discharges, length of stay, department analysis, and readmission analysis |

The project also contains `data/raw/hospital_raw_data.csv`, which is a raw hospital dataset copy. The processed hospital dataset is stored at `data/processed/hospital_final.csv`.

The final dataset is used for hospital analysis and KPI generation, subject to the paths configured in the project scripts.

## 2. Department Resources

| Property | Details |
|---|---|
| Filename | `department_resources.csv` |
| Location | `data/raw/department_resources.csv` |
| Number of department records | 6 |
| Source | Prepared by the project team |
| Purpose | Bed capacity and available department resources, including doctors, nurses, and technicians |

The department resource values are project assumptions unless independently verified against hospital records.

## 3. Equipment Utilization

| Property | Details |
|---|---|
| Filename | `equipment_utilization.csv` |
| Location | `data/raw/equipment_utilization.csv` |
| Number of records | 366 |
| Source | Generated by `scripts/generate_equipment_data.py` |
| Random seed | 42 |
| Purpose | Equipment utilization analysis |

This dataset is simulated for the project. It should not be interpreted as actual hospital equipment usage.

## 4. Processed Datasets and KPI Outputs

The `data/processed/` directory contains:

- `hospital_cleaned.csv` — cleaned hospital dataset.
- `hospital_featured.csv` — dataset with engineered features.
- `hospital_final.csv` — final hospital dataset.
- `hospital_final_dataset.xlsx` — Excel version of the final dataset.
- `kpi_overall.csv` — overall hospital KPIs.
- `kpi_monthly.csv` — monthly KPIs.
- `kpi_department.csv` — department-level KPIs.
- `kpi_region.csv` — region-level KPIs.

The KPI tables are generated by the project scripts.

## 5. Data Limitations

- Department resource figures represent project assumptions unless independently verified.
- Equipment utilization data is simulated.
- Results depend on the source dataset, preprocessing, date range, filters, and KPI definitions.
- Simulated or assumed values should be distinguished from measured hospital data when interpreting results.
