# KPI Documentation

## KPI scope

The current dashboard uses seven primary KPIs generated by `scripts/generate_hospital_kpis.py` and stored in the `KPI Summary` sheet of `data/hospital_final_dataset.xlsx`.

## Patient KPIs

### Total Admissions

- **Formula:** Number of records in the validated patient analysis dataset.
- **Implementation:** `len(patients)`
- **Source:** `hospital data analysis.csv` / `Patient Data`
- **Current value:** 984
- **Limitation:** This is a patient-record count, not a verified count of admission events because no admission date or event identifier is available.

### Average Length of Stay

- **Formula:** `mean(Length_of_Stay)`
- **Source:** `hospital data analysis.csv` / `Patient Data`
- **Current value:** 37.663617886179
- **Validation:** All source length-of-stay values are positive.
- **Limitation:** The dataset does not provide admission or discharge dates for independently reconstructing stay duration.

### Readmission Rate (%)

- **Formula:** `count(Readmission == Yes) / patient record count * 100`
- **Implementation:** Readmission values are normalized to lowercase and mapped to a flag.
- **Source:** `hospital data analysis.csv` / `Patient Data`
- **Current value:** 26.829268292683%
- **Validation:** 264 Yes and 720 No records; no unrecognized values.
- **Limitation:** No readmission dates or event history are available.

### Average Patient Cost

- **Formula:** `mean(Cost)`
- **Source:** `hospital data analysis.csv` / `Patient Data`
- **Current value:** 8367.479674796748
- **Limitation:** The dataset does not define currency, cost period, or cost category in the available fields.

### Recovery Rate (%)

- **Formula:** `count(Outcome == Recovered) / patient record count * 100`
- **Source:** `hospital data analysis.csv` / `Patient Data`
- **Current value:** 60.060975609756%
- **Validation:** 591 Recovered and 393 Stable records.
- **Limitation:** The source contains outcome labels but no clinical outcome timeline.

## Resource KPIs

### Bed Occupancy Rate (%)

- **Formula:** `sum(beds_occupied) / sum(beds_allocated) * 100`
- **Source:** `hospital-resource-allocation-records.csv` / `Resource Data`
- **Current value:** 90.713706407137%
- **Validation:** No record has occupied beds above allocated beds.
- **Zero denominator behavior:** The generated KPI script returns `NaN` if total allocation is zero; the dashboard helper displays `N/A` when the filtered denominator is zero.
- **Limitation:** The total is aggregated across allocation records and is not automatically a unique hospital-wide census.

### Staff On-Duty Rate (%)

- **Formula:** `sum(staff_on_duty) / sum(staff_allocated) * 100`
- **Source:** `hospital-resource-allocation-records.csv` / `Resource Data`
- **Current value:** 93.888710196205%
- **Zero denominator behavior:** The generated KPI script returns `NaN` if total allocation is zero; the dashboard helper displays `N/A` for a filtered zero denominator.
- **Limitation:** Aggregated allocation records do not establish unique staff headcount.

## Dashboard-only resource measures

The Resource Utilization page also calculates filtered measures using `resource_utilization_metrics()`:

| Measure | Formula | Source columns |
|---|---|---|
| Equipment Utilization | `sum(equipment_in_use) / sum(equipment_allocated) * 100` | `equipment_in_use`, `equipment_allocated` |
| Available beds | `beds_allocated - beds_occupied` | `beds_allocated`, `beds_occupied` |
| Available staff | `staff_allocated - staff_on_duty` | `staff_allocated`, `staff_on_duty` |
| Available equipment | `equipment_allocated - equipment_in_use` | `equipment_allocated`, `equipment_in_use` |

For these dashboard calculations, numeric values are coerced with `errors="coerce"` and missing values are filled with zero. Rates with zero denominators display as `N/A`.

## KPI validation evidence

Independent calculations from the source CSVs matched the workbook KPI Summary values for all seven primary KPIs. Exact values and test evidence are documented in:

## Unsupported KPI areas

The current data does not support valid KPIs for:

- Discharges
- Patient movement
- Daily patient census
- Peak patient load
- Department performance
- Department efficiency
- Patient-level resource linkage
